# Smart Clipboard & Text Expander

> **Personal Text Memory — Save Once, Paste Anywhere.**  
> 100% local-first. Zero cloud. Your data stays on your device.

---

## Quick Start (Local Dev)

```bash
# 1. Create Flutter project scaffolding (generates android/, ios/, etc.)
flutter create . --org com.smartclip --project-name smart_clipboard

# 2. Copy the Android files I created into the generated structure:
#    android/app/src/main/AndroidManifest.xml  ← replace with my version
#    android/app/src/main/res/xml/network_security_config.xml
#    android/app/src/main/kotlin/com/smartclip/smartclipboard/MainActivity.kt

# 3. Generate launcher icons (requires ImageMagick)
chmod +x scripts/generate-icons.sh
./scripts/generate-icons.sh

# 4. Get dependencies
flutter pub get

# 5. Run
flutter run
```

## Android Setup Details

### HTTP Cleartext Traffic

**Problem**: Android 9+ (API 28) blocks HTTP cleartext by default.  
**Solution**: `network_security_config.xml` allows HTTP for all domains.

```xml
<!-- android/app/src/main/res/xml/network_security_config.xml -->
<network-security-config>
    <base-config cleartextTrafficPermitted="true">
        <trust-anchors>
            <certificates src="system" />
        </trust-anchors>
    </base-config>
</network-security-config>
```

Referenced in `AndroidManifest.xml`:
```xml
<application
    android:networkSecurityConfig="@xml/network_security_config"
    android:usesCleartextTraffic="true"
    ...>
```

**Why allow ALL domains?**  
Smart Clipboard only accesses the network through Share Sheet — receiving
shared text from Chrome/Gmail/Messenger. It does NOT make outbound API calls.
No analytics, no ads, no BaaS (Master Spec Rules 2, 8).

### App Icon

Adaptive icons (API 26+) use vector XML:
- `res/drawable/ic_launcher_foreground.xml` — clipboard + checkmark + sparkle
- `res/drawable/ic_launcher_background.xml` — solid brand blue (#3D5AFE)
- `res/mipmap-anydpi-v26/ic_launcher.xml` — adaptive icon definition

Legacy PNG fallbacks generated by `scripts/generate-icons.sh`:
- `res/mipmap-{mdpi,hdpi,xhdpi,xxhdpi,xxxhdpi}/ic_launcher.png`

## Architecture

- **State Management**: Riverpod (unified across entire app)
- **Database**: SQLite via `sqflite` with WAL mode
- **Data Sync**: File-based only (Flutter ↔ IME process boundary)
- **Backup**: AES-256-GCM with PBKDF2 key derivation
- **Tests**: Unit tests for normalizer, expansion engine, privacy heuristic, PBKDF2
